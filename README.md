## One-Line Roast: The Gadget You Use Every Day

A single original roast line (at most 200 characters) for the gadget we all
rely on daily: our wireless earbuds. Instead of the tired battery-dies joke,
it frames the earbuds as a couple having a dramatic breakup mid-call — one
drops out, the other pretends nothing happened, then both die at once.

Run `python3 main.py` and the line is written to `entry.txt` in
`$MAKEFUN_OUTPUT_DIR` (default `/output`). Python 3, standard library only,
no network, deterministic output.
